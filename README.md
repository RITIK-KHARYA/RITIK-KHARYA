## Personal Projects (My Work)

- **Shadcncanvas** — drag-and-drop visual builder for shadcn/ui; export production-ready React ([live](https://shadcncanvas.vercel.app))
- **Leafra** — chat with your PDFs via a RAG pipeline over vector search ([live](https://leafra-eight.vercel.app))
- **GoBouncer** — self-hosted rate limiting API in Go + Redis (sliding window, GCRA, Prometheus)
- **GoBouncer SDK** — drop-in Node/Python SDK with Express, Hono, Fastify, Koa, Elysia middleware
- **Dotty** — turns images and video into ASCII art (Go engine, React frontend)
- **go-code-chunk** — semantic code chunking in Go (Tree-sitter AST, for LLM context) — in progress
- **Diarycover** — microblogging site to share thoughts ([live](https://diarycover.vercel.app))

## Run Locally

```bash
git clone https://github.com/RITIK-KHARYA/portfolio.git && cd portfolio
bun install
cp .env .env.local
bun dev
```

Open [http://localhost:3000](http://localhost:3000). See [PROJECT_STRUCTURE.md](./PROJECT_STRUCTURE.md) for the architecture.
